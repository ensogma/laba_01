Python-пакет `toolkit` с CLI: калькулятор и конвертер величин.

## Установка

```
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Использование

Калькулятор:

```
python -m toolkit calc "2 + 3 * 4"          # 14.0
python -m toolkit calc "(1 + 2) * 3"        # 9.0
python -m toolkit calc -- "-(2 + 3)"        # -5.0
```

Конвертер:

```
python -m toolkit convert 1 --from km --to m      # 1000.0
python -m toolkit convert 212 --from f --to c     # 100.0
```

Помощь: `python -m toolkit --help`

## Что поддерживается

- Калькулятор: целые и вещественные числа, `+ - * /`, унарные `+` и `-`, скобки, пробелы игнорируются.
- Конвертер:
  - длина: `mm`, `cm`, `m`, `km`
  - масса: `g`, `kg`
  - температура: `c`, `f`, `k`
- Регистр единиц не учитывается (`KM` = `km`).
- Результат всегда `float`.

## Ошибки

Ошибка печатается в stderr, код возврата `2`. Успех: код `0`.

Обрабатываются: пустое выражение, недопустимый символ, пропущенный операнд, два бинарных оператора подряд, деление на ноль, непарные скобки, неизвестная единица, несовместимые единицы, температура ниже абсолютного нуля, неверное число.

## Принятые решения

- `.5` и `5.` считаются числами, а `1.2.3` ошибкой.
- Неявное умножение не поддерживается: `2(3)` и `(1+2)(3+4)` дают ошибку.
- `1++2`, `1+-2`, `3*-2` разрешены, а `1+++2` и `--5` нет (после унарного знака второй знак подряд запрещён).
- Отрицательные длина и масса разрешены.


## Как устроен код

- `calculator.py`: три отдельных этапа.
  - `tokenization` ловит недопустимые символы и неверные числа.
  - `validation` проверяет структуру выражения.
  - `calculation` переводит токены в RPN и считает стеком.
- `converter.py`: перевод через базовую единицу (метры, граммы, градусы цельсия).
- `errors.py`: все ошибки наследуются от `ToolkitError`, CLI ловит только её.
- `__main__.py`: CLI на `argparse`, весь вывод только здесь.
